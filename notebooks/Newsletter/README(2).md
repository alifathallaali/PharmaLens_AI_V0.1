# PharmaLens Intelligence Newsletter — Starter Kit

Purpose: build a Substack + LinkedIn newsletter that turns pharma/biotech news into decision-oriented commercial intelligence and feeds qualified users toward PharmaLens AI.

## Core positioning
**PharmaLens Intelligence**
The pharma intelligence snapshot for commercial, medical and strategic decision-makers.

Editorial promise:
**News → Data → Interpretation → Commercial implication → Decision**

## Recommended cadence
- LinkedIn: 3 short posts/week
- Substack: 1 flagship weekly issue
- Monthly: 1 market/strategy deep dive
- Optional: daily automated intelligence brief inside PharmaLens, not public by default

## Launch sequence
1. Create Substack publication and visual identity.
2. Publish a welcome/manifesto post.
3. Publish 3 strong flagship issues before heavy promotion.
4. Repurpose each issue into 3–5 LinkedIn posts and 1 short-form video.
5. Add a CTA to PharmaLens only when the analysis genuinely benefits from interactive data.
6. Track subscribers, open rate, clicks, LinkedIn saves/comments, and PharmaLens signups.

## Important editorial rule
Do not simply summarize news. Every issue should answer: “So what does this mean for pharma teams?”
